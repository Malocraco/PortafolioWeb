PoliCom - Plataforma de Marketing & Comunicaciones

Descripción del Proyecto

Sistema diseñado para la agilización y optimización de campañas de marketing, permitiendo el envío eficiente de comunicaciones mediante correo electrónico y SMS. Incluye además un módulo integrado para acortar enlaces a través del consumo de la API de Bitly, facilitando el seguimiento y efectividad de cada mensaje.

  • Automatización y distribución de campañas vía Email y SMS
  • Acortador de enlaces integrado consumiendo la API de Bitly
  • Optimización en la entrega y agilización operativa
  • Autenticación segura y panel de gestión
